# Microprocessors

Coursework for microprocessors labs targeting an Arduino Nano with an ATmega328P.

## Labs

| Lab | Description | Source |
| --- | --- | --- |
| Lab 1 C | Blink the LED connected to Nano pin D8 using C and AVR registers. | [lab1_C](lab1_C/) |
| Lab 1 ASM | Blink the LED connected to Nano pin D8 using AVR assembly. | [lab1_ASM](lab1_ASM/) |

## Toolchain

- MPLAB X / MPLAB for project configuration and builds
- Microchip XC8 compiler
- CMake and Ninja, generated by the MPLAB project integration
- Arduino Nano with the ATmega328P

The generated project files under each lab directory expect the Microchip device pack to be installed locally. Paths in the generated build tree are machine-specific and are not committed.

## Build and upload

Open either lab directory in VS Code with the MPLAB project integration enabled. Build the project to generate a HEX file under that lab's `out/` directory. The workspace task **Upload MPLAB HEX to Arduino Nano** uploads the newest verified HEX file to the configured Nano port.

Before uploading, make sure the source has been rebuilt after the last source change and that the board port in the task configuration is correct.

## Repository layout

```text
lab1_C/       C implementation and MPLAB project files
lab1_ASM/     AVR assembly implementation and MPLAB project files
_build/       local generated build trees (ignored)
out/          local compiler output and HEX files (ignored)
```
