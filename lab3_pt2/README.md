# lab3_pt2

Arduino Nano / ATmega328P keypad and LED exercise written in C.

## Structure

| Path       | Purpose                               |
|------------|---------------------------------------|
| `main.c`   | Keypad scanning and LED control source |
| `README.md` | Project-specific documentation        |
| `.vscode/lab3_pt2.mplab.json` | MPLAB project configuration |

The MPLAB project configuration targets the ATmega328P with XC8 3.10 and the
ATmega_DFP 3.6.299 device pack. Install those components in MPLAB X before
building.
